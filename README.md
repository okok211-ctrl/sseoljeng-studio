# 썰쟁 Studio v13.4 Workflow Edition

## 이번 변경
- GPT 분할 생성 마법사를 왼쪽 설정 영역 최상단으로 이동
- 오른쪽의 `롱폼 붙여넣기` 작업창과 같은 높이에서 바로 사용할 수 있도록 작업 동선 개선
- 프롬프트 복사 → ChatGPT 생성 → Studio 붙여넣기 과정에서 불필요한 스크롤 최소화
- 기존 분할 생성, 캐릭터, 설계도, 이미지, 쇼츠, SRT, 저장 기능 유지

## 권장 작업 순서
1. 왼쪽 최상단에서 GPT 분할 생성 마법사를 시작합니다.
2. 현재 프롬프트를 복사해 ChatGPT에 붙여넣습니다.
3. 생성된 문단을 오른쪽 `롱폼 붙여넣기`에 바로 붙여넣습니다.
4. `완료하고 다음`을 눌러 다음 구간을 계속 작성합니다.

# 썰쟁 Studio v13.1 Split Prompt Edition

## 핵심 추가 기능
- GPT 분할 생성 마법사
- 20·40·60·사용자 지정 문단 수 자동 분할
- 3·5·7·10문단 단위 선택
- 단계별 프롬프트 생성, 복사, 완료 후 다음 단계 이동
- 마지막 구간 전까지 결말 금지, 이전 구간 반복 금지 규칙 자동 적용
- 설계도·등장인물·문체를 모든 단계 프롬프트에 포함

## 권장 사용 순서
1. 프로젝트와 등장인물을 설정합니다.
2. 스토리 설계도를 생성하거나 작성합니다.
3. GPT 분할 생성 마법사에서 5문단씩을 선택합니다.
4. 현재 프롬프트를 복사하여 같은 ChatGPT 대화에 붙여넣습니다.
5. 답변을 받은 뒤 완료하고 다음을 누릅니다.
6. 마지막 단계까지 작성한 원고 전체를 롱폼 붙여넣기 탭에 붙여넣습니다.
7. 붙여넣은 롱폼 확인 후 제작 자료를 생성합니다.

# 썰쟁 Studio v13.0 Production Edition

롱폼 원고는 ChatGPT에서 작성하고, Studio는 스토리 설계와 제작 자료 생성을 담당합니다.

## 작업 흐름

1. 프로젝트 주제와 등장인물 설정
2. 스토리 설계도 작성 또는 AI 생성
3. `GPT 롱폼 프롬프트` 생성 후 ChatGPT에 복사
4. ChatGPT가 작성한 번호 포함 원고를 `롱폼 붙여넣기` 탭에 그대로 입력
5. 문단 확인 후 이미지 프롬프트, 쇼츠, 썸네일, 유튜브 정보, SRT, 음성용 원고 생성

문단 수는 15~100문단 범위에서 선택 또는 직접 입력할 수 있습니다.
