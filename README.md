# 썰쟁 Studio v13.9.6 궁금증형 나레이션·4컷 엔딩 수정

## 변경 내용
- 제작 자료 전체 생성, 조회수형 쇼츠, 쇼츠 재생성이 모두 같은 공통 쇼츠 엔진을 계속 사용합니다.
- 1~3컷 나레이션은 사건을 자세히 설명하지 않고 발견 → 충격 → 결정적 단서까지만 보여줍니다.
- 화면 문구와 나레이션이 같은 내용을 반복하지 않도록 규칙을 강화했습니다.
- 4컷 화면 문구는 `결말은 / 본편에서`로 고정합니다.
- 4컷 나레이션은 `사연에 맞는 마지막 충격 한 문장 + 결말은 본편에서 확인해 보세요.` 구조로 생성합니다.
- 예: `그 음성파일 하나가 남편의 모든 거짓말을 밝혀냈습니다. 결말은 본편에서 확인해 보세요.`
- 초굵은 압축형 한국어 디스플레이 글꼴 지시는 그대로 유지됩니다.
