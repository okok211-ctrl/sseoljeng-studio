# 썰쟁 Studio v13.9.5 쇼츠 공통 빌더

## 핵심 변경
- 제작 자료 전체 생성의 쇼츠, 상단 조회수형 쇼츠 버튼, 하단 조회수형 쇼츠 새 생성 버튼이 모두 `buildUnifiedShortsPrompt()` 하나를 사용합니다.
- 앞으로 쇼츠 규칙을 수정하면 세 경로에 동시에 적용됩니다.
- 조회수형 후킹, 초강력 압축형 디스플레이 글꼴, 빨강·노랑 강조, 검은 외곽선, 4컷 고정 엔딩 규칙을 그대로 유지합니다.
- 4컷 화면 문구: `결말은 / 본편에서`
- 4컷 나레이션: `결말은... / 본편에서 확인해 보세요.`

## 버튼 동작
- `제작 자료 전체 생성`: 공통 빌더의 embedded 모드 사용
- 상단 `조회수형 쇼츠`: `generateShortsOnly()` 호출
- 하단 `조회수형 쇼츠 생성`: 동일한 `generateShortsOnly()` 호출
