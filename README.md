# 썰쟁 Studio v8.1.0 Shorts

## 추가 기능
- 롱폼과 독립된 쇼츠 전용 생성 버튼
- 같은 사연에서 쇼츠 1개/3개/5개 반복 생성
- 현재 롱폼 또는 주제만 사용 선택
- 후킹형/반전형/감동형/분노·사이다형 선택
- 기존 쇼츠 결과에 추가하거나 교체 가능
- 각 쇼츠는 4컷, 컷별 독립 9:16 이미지 프롬프트
- 롱폼, 본문 이미지, 썸네일, 일본어 자료는 쇼츠 재생성 시 유지
- SRT에서 문단 글자 수 표시 제거 유지
- 썸네일 A/B/C 강렬한 문구 규칙 유지
