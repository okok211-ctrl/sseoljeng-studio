# 썰쟁 Studio v12.2.1

## 이번 변경사항

- 0문단 제거 유지: 1문단 오프닝, 2~19문단 본문, 20문단 엔딩
- 글자 수 강제 검증 제거
- 문단 길이는 프롬프트에서만 권장
  - 1문단: 약 250자 (권장 220~280자)
  - 본문: 약 400자 (권장 380~450자)
  - 엔딩: 약 340자 (권장 300~380자)
- 글자 수가 권장 범위를 벗어나도 생성 실패로 처리하지 않음
- 문단 번호 누락과 본문 중간 엔딩 문구만 자동 보정
- 실제 글자 수는 각 문단 아래 참고용으로 표시

배포 시 기존과 동일하게 프로젝트 전체를 업로드하세요.

- 화면·브라우저 제목·package.json 버전 표시를 v12.2.1로 통일
