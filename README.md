# 썰쟁 Studio v13.9.3 조회수형 쇼츠 통합

## 이번 버전 핵심
- `제작 자료 전체 생성`과 `조회수형 쇼츠 생성·재생성`이 완전히 같은 공통 쇼츠 엔진을 사용합니다.
- 영화 예고편처럼 점잖고 추상적인 문구 대신 유튜브 사연 채널용 자극형 후킹을 생성합니다.
- 1컷은 사건의 구체적인 핵심 단어가 들어간 질문형 또는 폭로형으로 시작합니다.
- 2컷은 더 황당한 사실을 암시하고, 3컷은 충격적인 단서나 반격 직전에서 끊습니다.
- 화면 문구는 2~3줄, 8~24자 안팎이며 흰색 굵은 글자와 빨강·노랑 핵심 강조, 검은 외곽선과 강한 그림자를 지시합니다.
- 나레이션은 본문 전체를 설명하지 않으면서도 해당 사건의 충격적인 상황은 직접적으로 전달합니다.
- 4번째 컷 화면 문구는 `결말은 / 본편에서`, 나레이션은 `결말은... / 본편에서 확인해 보세요.`로 고정합니다.

## 유지된 기능
- 캐릭터 선택과 이번 이야기 사용 분리
- 여주 기준 얼굴 지정
- GPT 분할 생성 마법사
- 썸네일 강렬한 헤드라인
- 이미지·SRT·유튜브 정보 생성
