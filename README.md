# 썰쟁 Studio v13.7 Story Cast Selection

## 이번 버전 핵심
- 캐릭터 등록과 이번 이야기 사용을 분리했습니다.
- `이번 이야기에서 사용`이 체크된 인물만 GPT·이미지·쇼츠 프롬프트에 들어갑니다.
- `⭐ 이야기 주인공으로 지정` 기능을 추가했습니다.
- 주인공은 한 명만 지정됩니다.
- 현재 여주 선택 시 다른 여주 프리셋은 자동으로 미사용 처리됩니다.
- 기존 프로젝트에서 여러 여주가 동시에 활성화된 경우, 선택된 여주만 남기도록 자동 정리합니다.
- GPT 프롬프트에 조연 전원을 억지로 등장시키지 말라는 규칙을 추가했습니다.

## 사용 방법
1. 캐릭터 카드에서 사용할 인물을 선택합니다.
2. `이번 이야기에서 사용`을 체크합니다.
3. 중심 인물은 `⭐ 이야기 주인공으로 지정`을 체크합니다.
4. 설정 저장을 누릅니다.
5. GPT 분할 생성 마법사에서 프롬프트를 생성합니다.

등록만 해둔 캐릭터는 보관함에 남아 있지만, 사용 체크를 하지 않으면 해당 작품의 프롬프트에는 포함되지 않습니다.
