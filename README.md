# 썰쟁 Studio v13.9.7 쇼츠 완전 동일 엔진

## 수정 핵심
- `제작 자료 전체 생성`의 쇼츠를 다른 복합 프롬프트에서 생성하지 않습니다.
- 전체 생성도 `쇼츠만 생성`과 완전히 동일한 `callGenerate('shorts')` 경로를 별도로 호출합니다.
- 상단 조회수형 쇼츠 버튼과 하단 조회수형 쇼츠 생성 버튼도 같은 `generateShortsOnly()` 함수를 사용합니다.
- 따라서 세 버튼 모두 화면 문구, 나레이션, 글꼴, 4컷 엔딩 규칙이 동일합니다.
- 4컷 나레이션은 `사연별 마지막 충격 한 문장 + 결말은 본편에서 확인해 보세요.` 형식입니다.

## 참고
생성 개수와 스타일은 왼쪽 `조회수형 쇼츠 생성` 설정값을 전체 생성에서도 그대로 사용합니다.
