# 썰쟁 Studio v5.2 AI

## 주요 수정
- 15/20문단을 5문단 단위로 분할 생성
- 생성 후 0~선택 문단까지 자동 검사
- 누락 문단 발견 시 해당 구간 자동 재시도
- 일본어판을 5문단 단위로 번역
- 일본어 결과에 한글이 섞이면 자동 재시도 및 차단
- 캐릭터 설정 보관함 추가(브라우저 로컬 저장)
- Gemini 사용 가능 모델 자동 선택 유지

## 설치
압축을 풀고 폴더 안의 파일과 `api` 폴더를 GitHub 저장소 최상위에 덮어쓴 뒤 Commit합니다.
Vercel의 `GEMINI_API_KEY`는 기존 값을 그대로 사용합니다.
