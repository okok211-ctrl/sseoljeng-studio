# 썰쟁 Studio v16.2 선택 문단 품질 수정

## 새 기능
- 왼쪽 `🧠 품질 검사` 버튼 또는 상단 `품질 리포트` 탭에서 현재 원고를 다시 검사합니다.
- 중복 감정, 사건 재요약, 정보 밀도 부족, 마지막 5문단 역할 중복, 엔딩 누락을 문단 번호와 함께 표시합니다.
- 수정 권장 문단은 체크박스로 자동 표시됩니다.
- `선택 문단만 재생성`을 누르면 선택한 문단만 AI가 다시 작성합니다.
- 선택하지 않은 문단은 원문 그대로 유지합니다.
- 재생성 시 앞뒤 문단과 설계도를 함께 참고해 연결이 끊기지 않도록 합니다.
- 수정 후 SRT와 음성용 원고도 자동 갱신합니다.

## 사용 순서
1. 롱폼 원고를 생성하거나 붙여넣습니다.
2. `🧠 품질 검사`를 누릅니다.
3. `품질 리포트` 탭에서 수정 권장 문단을 확인합니다.
4. 고칠 문단만 체크합니다.
5. `✨ 선택 문단만 재생성`을 누릅니다.
6. 수정 결과가 기존 롱폼 원고에 자동 반영됩니다.
