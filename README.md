# 썰쟁 Studio v13.9.2 YouTube Hook Fix

## 이번 버전 핵심
- 쇼츠 생성 기본 방향을 영화 예고편형에서 유튜브 자극형 후킹 스타일로 변경했습니다.
- `쇼츠만 생성`과 `제작 자료 전체 생성`의 쇼츠 부분에 같은 규칙을 적용했습니다.
- 1~3컷은 롱폼을 요약하지 않고 강한 의문·충격·분노·배신감으로 클릭을 유도합니다.
- 화면 문구는 5~12자의 짧고 강한 문구로 생성합니다.
- 쇼츠 이미지 문구는 큰 흰색 굵은 글자, 두꺼운 검은 외곽선, 은은한 그림자로 지시합니다.
- 4번째 컷 화면 문구는 항상 `결말은 / 본편에서`로 고정합니다.
- 4번째 컷 나레이션은 항상 `결말은... / 본편에서 확인해 보세요.`로 고정합니다.

기존 캐릭터 선택, 여주 얼굴 지정, GPT 분할 생성, 썸네일 헤드라인 기능은 그대로 유지됩니다.
