# 썰쟁 Studio v14.2 이미지 문단 범위 표시

## 이미지 프롬프트 개선
- 각 이미지마다 `[사용 문단: 시작문단~끝문단]`을 표시합니다.
- 전체 문단을 이미지 수에 맞춰 순서대로 고르게 자동 배분합니다.
- 각 범위에서 실제 이미지로 사용할 장면은 `[대표 장면 문단]`에 별도로 표시합니다.
- 문단 범위는 서로 겹치거나 빠지지 않습니다.
- `이미지 프롬프트` 단독 생성과 `제작 자료 전체 생성` 양쪽에 동일하게 적용됩니다.

## 출력 예시
- `[사용 문단: 1문단~5문단]`
- `[대표 장면 문단: 4문단]`
- `[장면 설명]`
- `[생성 프롬프트]`

기존 쇼츠 엔진과 썰쟁 Style Engine은 그대로 유지됩니다.
