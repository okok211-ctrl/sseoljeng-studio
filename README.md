# 썰쟁 Studio v9.1.0 — 장편 안정 생성

## 핵심 업그레이드
- 문단 수 15/20/30/40/50/60/80 및 직접 입력(10~100)
- 긴 글을 쓰기 전에 스토리 설계도와 Story Bible 자동 생성
- 5~10문단 단위 구간 생성으로 장편 이야기 이탈 방지
- 인물 나이·직업·관계·성격·결말을 설계도에 고정
- 반복 에피소드와 즉흥 설정 추가 금지 프롬프트 적용
- 완성 후 설정 충돌·미회수 복선·반복 구간 검사
- 스토리 밀도 및 작성 품질 선택
- 음성 AI용 원고: 시간·번호·글자 수 제거, 10문단 단위 Part 분할
- SRT 글자 수 표기 제거
- 쇼츠 독립 1/3/5개 생성과 썸네일 A/B/C 문구 기능 유지

## 권장 사용 순서
1. 주제와 캐릭터 설정
2. 문단 수 40, 밀도 높음 또는 영화급 선택
3. `롱폼 안정 생성` 클릭
4. 필요하면 `설정 검사` 실행
5. `음성용` 또는 `SRT 자막` 사용

긴 원고는 설계도 생성 후 여러 번의 API 호출로 나누어 작성되므로 20문단보다 시간이 더 걸릴 수 있습니다. 생성 중 브라우저 창을 닫지 마세요.
