# 썰쟁 Studio v14.0 짧은 나레이션·초강력 글꼴

## 쇼츠 공통 엔진 변경
- 제작 자료 전체 생성, 상단 조회수형 쇼츠, 하단 조회수형 쇼츠 생성이 같은 엔진을 사용합니다.
- 1~3컷 나레이션은 12~25자 안팎의 한 문장으로 제한합니다.
- 장면을 길게 설명하거나 화면 문구를 반복하지 않습니다.
- 종결어미를 `~했어요`, `~였죠`, `~더군요`, `~했습니다` 등으로 자연스럽게 섞습니다.
- 4컷은 사연별 마지막 충격 한 문장 뒤에 `결말은 본편에서 확인해 보세요.`를 붙입니다.

## 화면 문구와 글꼴
- 일반 고딕체, 기본 산세리프, 뉴스 자막체를 금지합니다.
- 초굵은 압축형 한국어 디스플레이 글꼴, 예능 자막형, 포스터형, 유튜브 바이럴 썸네일형을 지시합니다.
- 흰색 글자에 빨강·노랑 핵심 강조, 매우 두꺼운 검은 외곽선과 강한 입체 그림자를 적용합니다.

## 유지 기능
- 캐릭터 선택 및 여주 얼굴 고정
- GPT 분할 생성
- 이미지·썸네일·SRT·유튜브 정보 생성
