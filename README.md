# 썰쟁 Studio v12.1.0

## 핵심 변경
- 0문단을 완전히 제거하고 1문단부터 시작합니다.
- 1문단은 오프닝(후킹 + 구독 문구 + 핵심 갈등 예고)입니다.
- 2문단부터 마지막 전 문단까지는 본문 진행만 작성합니다.
- 마지막 번호 문단에서만 엔딩, 시청자 질문, 댓글 유도, 구독·좋아요 문구를 작성합니다.
- 본문을 3~4문단 단위로 나누어 생성하여 10문단에서 조기 마무리되는 현상을 줄였습니다.
- 중간 본문에서 엔딩 문구가 감지되거나 글자 수가 벗어나면 최대 4회 자동 재작성합니다.
- 문단 기준: 1문단 220~280자 / 중간 본문 380~450자 / 마지막 문단 300~380자.
- 캡컷 입력 제한을 고려해 중간 본문은 450자를 절대 넘기지 않도록 프롬프트와 검증 기준을 통일했습니다.

## 사용
Vercel에 폴더 전체를 배포한 뒤 `롱폼 안정 생성` 또는 `전체 자동 생성`을 사용하세요.
