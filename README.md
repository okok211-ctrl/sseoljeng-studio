# 썰쟁 Studio v14.3 전체생성 이미지 공통 엔진

## 수정 핵심
- `✨ 제작 자료 전체 생성`에서도 이미지 부분을 별도 `callGenerate('images')`로 생성합니다.
- 따라서 `🖼 이미지 프롬프트` 버튼과 제작 자료 전체 생성이 완전히 같은 이미지 프롬프트를 사용합니다.
- 각 이미지마다 아래 항목이 동일하게 표시됩니다.
  - `[사용 문단: 1문단~5문단]`
  - `[대표 장면 문단: 4문단]`
  - `[장면 설명]`
  - `[생성 프롬프트]`
- 문단 범위는 이미지 수에 맞춰 겹침과 누락 없이 자동 배분됩니다.

## 유지 기능
- 짧은 쇼츠 나레이션
- 초강력 디스플레이 글꼴
- 썰쟁 Style 유튜브 정보
- 쇼츠 공통 엔진
