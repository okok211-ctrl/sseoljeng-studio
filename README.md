# 썰쟁 Studio v16.3 선택 문단 재생성 안정화

## 이번 수정
- `api/generate.js`에 `paragraphrepair` 전용 설정을 추가했습니다.
- 선택 문단 재생성은 낮은 창작 온도와 제한된 모델 재시도로 원문 유지력을 높였습니다.
- 앞뒤 문단 연결, 핵심 사건, 시점, 말투를 유지하도록 프롬프트를 강화했습니다.
- 새 인물·새 사건·새 증거를 임의로 추가하지 못하도록 제한했습니다.
- Gemini 429 한도 오류가 발생해도 원고와 선택 상태는 그대로 유지됩니다.
- 프로젝트 전체 할당량이 소진된 경우 불필요하게 여러 모델을 계속 호출하지 않습니다.
- 화면에는 긴 내부 오류 대신 사용자가 이해하기 쉬운 안내를 표시합니다.

## 사용 순서
1. 롱폼 원고를 생성하거나 붙여넣습니다.
2. `🧠 품질 검사`를 실행합니다.
3. 품질 리포트에서 수정할 문단을 선택합니다.
4. `✨ 선택 문단만 재생성`을 누릅니다.
5. 성공하면 선택 문단만 교체되고 SRT·음성용 원고가 갱신됩니다.

## 참고
429 오류는 프로그램이 원고를 망가뜨린 것이 아니라 Gemini API 프로젝트의 사용 한도 문제입니다. 잠시 후 재시도하거나 Google AI Studio의 해당 프로젝트 사용 한도와 결제 상태를 확인해야 합니다.
