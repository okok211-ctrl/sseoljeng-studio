# 썰쟁 Studio v11.1 현실 몰입형 사연 엔진

기준 버전: v11.0.1

## 이번 변경
- 사용자가 제공한 3~5문단 예시와 같은 현실 몰입형 문체 적용
- 본문 문단 길이 420~470자
- 한 문단의 핵심 사건을 행동, 표정, 짧은 대화, 생각으로 충분히 전개
- 갈등이 의심 → 변명 → 책임 회피 → 더 큰 비밀 순으로 현실적으로 커지도록 지시
- 시청자가 화날 만한 반응도 처음부터 과장하지 않고 점점 본색이 드러나게 구성
- 문단 끝에 다음 내용이 궁금해지는 연결 문장 적용
- 1인칭 화자 이름 금지, 가족 이름 생성 금지
- 어려운 소설체와 지나치게 단순한 어린이식 문장 모두 억제
- "좋아. 여기서는..." 같은 작가 해설 출력 금지
- 기존 SRT 문단 번호·글자 수 제거 기능 유지
