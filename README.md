# 썰쟁 Studio v9.2.3 — Image Prompt Separate

기존 v9.2.2 기능을 유지하면서 본문 이미지 프롬프트를 별도로 생성하는 버튼을 추가한 버전입니다.

## 이번 수정
- `🖼 본문 이미지 프롬프트만` 버튼 추가
- 롱폼 원고를 유지한 채 이미지 프롬프트만 새로 생성
- 쇼츠·유튜브 정보·썸네일 결과를 덮어쓰지 않음
- 본문 이미지 비율은 16:9 가로형 고정
- 쇼츠는 9:16, 썸네일은 16:9 유지
- 콜라주·분할 화면·여러 장면 결합 금지
