# 썰쟁 Studio v4

태현 전용 무료 유튜브 사연 제작 정리 웹앱입니다.

## 핵심 기능
- ChatGPT 롱폼 요청문 생성
- 롱폼 대본 붙여넣기 및 프로젝트 저장
- 본문 이미지 프롬프트 자동 분할
- 썸네일 A/B/C안
- 쇼츠 4컷 초안
- 유튜브 제목/설명/해시태그/고정댓글
- 일본어판 요청문
- SRT 자막
- 이미지 직접 등록
- 캡컷용 ZIP

## 비용
OpenAI API를 사용하지 않으므로 별도 API 비용이 없습니다.
