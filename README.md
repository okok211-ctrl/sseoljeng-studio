# 썰쟁 Studio v16.0 Ending Flow Edition

## v16 핵심 변경
- 문단 수 선택에 24·26·28문단을 추가하고 30문단을 기본값으로 설정했습니다.
- 마지막 5개 문단의 역할을 분리해 결말 반복과 늘어짐을 줄였습니다.
- 이미 나온 이혼·배상·폐업·악역 몰락을 다음 문단에서 다시 요약하지 않도록 프롬프트 규칙을 강화했습니다.
- 마지막 문단은 주인공의 새로운 일상 장면으로 시작합니다.
- 마지막에 반드시 “오늘 이야기는 어떠셨나요?” 문구를 넣습니다.
- 사연과 연결된 공감 질문, 댓글 참여 유도, 구독·좋아요 부탁, 감사 인사를 순서대로 넣습니다.
- 엔딩 스타일 선택을 추가했습니다: AI 자동 추천 / 감동형 / 사이다형 / 희망형 / 토론형.
- 엔딩 길이를 짧고 강하게 또는 보통으로 선택할 수 있습니다.

## 보존 원칙
v15.0 원본은 수정하지 않았으며, v16은 별도 빌드입니다.
