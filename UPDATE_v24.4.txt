썰쟁 Studio v24.4 - 대본 등장인물 배정 / 클라우드 업로드 개선

1. 본문 탭 위 '🎭 대본 등장인물 분석 · 얼굴 배정'을 펼쳐 '본문에서 인물 찾기' 클릭.
2. 발견된 인물·호칭 후보에 저장된 캐릭터 얼굴을 배정하거나 수동으로 인물을 추가.
3. 이미지 프롬프트 생성 시 배정 정보를 지시문에 포함.
4. 캐릭터 클라우드 업로드 파일명을 안전한 영문 키로 자동 생성(한글 캐릭터명도 사용 가능).
5. 페이지 스크롤을 줄이기 위해 인물 목록은 2열 + 내부 스크롤(최대 290px).
6. 기존 본문/SRT 비교·맞춤법·글자 수 계산 및 캡컷 작업 기능은 그대로 유지.

주의: 자동 인물 분석은 브라우저 내 규칙 기반 후보 추출입니다. AI 의미 분석이 아니므로
같은 사람의 여러 호칭은 자동 병합되지 않을 수 있습니다. 사용자 확인 및 수동 추가가 필요합니다.
캐스팅 배정은 브라우저 localStorage에 프로젝트 이름별 저장됩니다. 다른 PC로 자동 동기화되지 않습니다.
클라우드 얼굴 사진은 기존 Supabase 계정으로 접근합니다.

배포: 이 폴더의 내용물을 GitHub 저장소 루트에 반영하면 Vercel이 배포합니다.
삭제한 파일: 웹 서비스 실행에 불필요한 Windows 배치/PowerShell 및 로컬 고속 렌더링 보조 파일.
삭제하지 않은 파일: index.html, api/, js/, vercel.json, package.json, Firebase 관련 웹 스크립트 및 정책.
