📝 자막 정리 · 원문 복원

CapCut 자동 캡션은 시간 기준점으로만 사용하고, 최종 자막 글자는 원본 대본 전체에서 다시 만듭니다. 자동캡션에서 빠진 단어도 원문에서 복원하며, 완료 후 원문 누락 검사를 표시합니다.
자동캡션의 시간값은 그대로 활용하고, 화면에 표시할 글자는 아래 원본 대본에서 다시 가져옵니다. 따라서 ‘제사→재사’ 같은 음성인식 오타를 원문으로 복원합니다.
원문 미등록
자동 캡션 SRT와 원본 대본을 넣으면 오타 교정 상태와 정리 후 자막 개수를 표시합니다.

🖼️ 이미지 넣기 · 타임라인 가이드

복잡한 설정 없이 CapCut 자동캡션 SRT와 이미 만들어 둔 이미지 프롬프트의 사용 문단을 연결해 이미지 넣을 시간을 계산합니다.
사용 순서 ① SRT 파일 불러오기 → ② 이미지 시간 계산 → ③ CapCut 타임라인의 표시된 시간에 이미지 넣기
이미지 프롬프트에서 ‘사용 문단: 4문단’ 같은 번호를 자동으로 읽습니다.
