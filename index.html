🖼 썸네일 Pro 설정

롱폼 이미지와 쇼츠 이미지는 장면에 필요한 인물만 자동 선택합니다. 대화·갈등 장면은 2~3명을 우선하고, 독백이나 결심 장면만 1명을 사용합니다.
사연의 핵심 갈등이 한눈에 보이는 상황형 단일 장면을 사용합니다. AI가 필요한 핵심 인물 1~3명을 자동 선택하며 콜라주·분할 화면·억지 빈 공간은 금지합니다.

🔥 조회수형 상황극 쇼츠 생성

전체 생성·상단 버튼·하단 버튼 모두 동일한 쇼츠 공통 엔진을 사용합니다. 1~3컷 나레이션은 12~25자, 4컷은 충격 한 문장 뒤 본편 유도로 끝납니다. ‘기존 결과에 추가’를 선택하면 같은 사연으로 쇼츠를 계속 쌓을 수 있습니다.
설계도와 캐릭터를 준비한 뒤 GPT 롱폼 프롬프트를 복사하세요.
작업 순서: 설계도 생성 또는 작성 → GPT 롱폼 프롬프트 복사 → ChatGPT에서 번호가 포함된 원고 작성 → 롱폼 탭에 그대로 붙여넣기 → 제작 자료 생성.
