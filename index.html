배포 및 연결

Vercel 무료 배포: GitHub에 파일을 올린 후 Vercel에서 저장소를 Import하고 Deploy를 누르세요.

실제 AI: Vercel 환경변수에 아래 값을 추가합니다.

OPENAI_API_KEY=발급받은 API 키
OPENAI_TEXT_MODEL=gpt-5-mini
OPENAI_IMAGE_MODEL=gpt-image-1

다른 기기에서도 프로젝트 이어쓰기: Supabase 프로젝트를 만들고 아래 환경변수를 추가합니다.

SUPABASE_URL=https://xxxx.supabase.co
SUPABASE_ANON_KEY=공개 anon key

키를 저장한 뒤 Vercel에서 Redeploy 하면 로그인과 클라우드 저장이 켜집니다.
