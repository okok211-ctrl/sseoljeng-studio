📝 자막 정리 · 원문 복원

CapCut 자동 캡션은 시간 기준점으로만 사용하고, 최종 자막 글자는 원본 대본 전체에서 다시 만듭니다. 자동캡션에서 빠진 단어도 원문에서 복원하며, 완료 후 원문/최종 글자 수와 누락 0자 여부를 표시합니다.
자동캡션의 시간값만 활용하고, 복원 버튼을 누를 때마다 현재 롱폼 탭의 실제 사연 원고만 다시 읽습니다. 이전 저장값·GPT 프롬프트·설계도는 복원 소스로 사용하지 않습니다. 실제 N문단 본문만 추출합니다.
원문 미등록
자동 캡션 SRT와 원본 대본을 넣으면 오타 교정 상태와 정리 후 자막 개수를 표시합니다.

🇯🇵 일본어 SRT · 블록 완전 분리 1:1 번역

현재 한국어 SRT의 시작/종료 시간은 그대로 유지하고, 각 한국어 자막 블록을 같은 번호의 일본어 자막으로 직접 번역합니다. 일본어 본문을 억지로 잘라 넣지 않기 때문에 뒤로 갈수록 내용이 밀리는 문제를 막습니다.
자막 번호·타임코드 고정 · 각 한국어 블록을 독립 요청으로 일본어 번역
