썰쟁 Studio v25.1 — 이미지 편집 타임라인

- 기존 v25.0 기능 유지
- SRT 파일 + 롱폼 원고 + 이미지 최대 30장(또는 그 이상)으로 이미지별 시작/종료/지속시간 자동 계산
- 이미지 파일명 자연 정렬(01.png~30.png 권장)
- CSV 및 JSON 편집 타임라인 다운로드
- 기존 이미지 프롬프트의 사용 문단 매칭 활용. 문단 참조가 없거나 이미지 수와 불일치하면 균등 문단 배정으로 대체

주의: CSV/JSON은 편집용 시간표입니다. CapCut에 불러오면 이미지가 영상 트랙에 자동 삽입되는 CapCut 네이티브 프로젝트가 아닙니다. 실제 캡컷 자동 배치 기능은 별도 프로젝트 포맷 연동이 필요합니다.
