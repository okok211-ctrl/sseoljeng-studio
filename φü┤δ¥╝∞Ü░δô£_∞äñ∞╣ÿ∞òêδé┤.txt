썰쟁 Studio v24.0 · 개인 캐릭터 클라우드 보관함

1. 수정 ZIP을 GitHub 저장소에 반영하고 Vercel 배포를 기다립니다.
2. 썰쟁 Studio → 캐릭터 페이지 → '클라우드 보관함' → '연결 설정'을 펼칩니다.
3. Supabase Settings → API Keys의 sb_publishable_... 키를 입력하고 '연결 확인'을 누릅니다.
4. Supabase Authentication → Users에서 만든 이메일/비밀번호로 로그인합니다.
5. 로컬 캐릭터를 선택하고 '선택 캐릭터 얼굴 클라우드 저장'을 누르거나 사진 파일을 업로드합니다.
6. 다른 컴퓨터에서 로그인한 뒤 사진 아래 '선택 캐릭터에 적용'을 누릅니다.

보안: service_role/secret 키는 절대 입력하지 마세요. character-images 버킷은 private 상태로 유지하고, 기존 owner UID 조건이 들어간 SELECT/INSERT/UPDATE/DELETE 정책 4개를 유지하세요. Supabase Auth에서 새 사용자 가입을 비활성화하면 개인 사용에 더 적합합니다.

참고: 이 기능은 사진을 클라우드에 보관하고 선택 캐릭터에 적용합니다. 캐릭터 이름·성격 등 모든 메타데이터를 자동 동기화하는 기능은 아닙니다. 기존 프로젝트 클라우드(Firebase) 기능과 별개입니다. 이 ZIP의 Supabase 연동은 배포 환경에서 로그인/업로드 실사용 검증이 필요합니다.
